SAARTHI: speak a snag

Say or type the snag in Hindi, Hinglish or English. SAARTHI fills a structured entry using only values from the fleet register, checks it against the records, reads it back, and signs it into the ledger when you confirm. If it is unsure, it asks instead of guessing.
